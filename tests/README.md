# `tests`：测试用例

本目录用于放置项目的单元测试与集成测试，确保 LangGraph 内核、各个 Agent 以及 RAG 子系统在迭代中保持稳定。

## 布局（分组示例）

- 根目录若干 `test_*.py` — 与 `pkg`、`config` 等主仓模块对应。

仓库根 **`pytest.ini`** 已设置 `pythonpath = src`。
