1. 核心业务逻辑

src/application/：存放具体的业务逻辑实现，比如服务类、业务流程处理、核心功能代码。
src/model/：定义数据模型（数据库表结构、Pydantic 模型等）。
src/repository/：负责数据访问层，和数据库交互（CRUD 操作）。
2. 接口与路由

src/router/：定义 API 路由，把接口路径和对应的处理函数绑定起来，是对外暴露的接口入口。
src/main.py：项目启动入口，初始化应用、挂载路由、配置服务。
3. 辅助功能

src/middleware/：中间件（如日志、鉴权、请求拦截等）。
src/config/：配置文件、环境变量加载。
src/response/：统一响应格式封装。
src/errmsg/：错误码、异常处理逻辑。
src/pkg/：公共工具、第三方包封装。

2. 代码编写要求
使用英文注释，避免使用中文
避免实现demo，所有功能都是要求可使用的
面向接口编程，确保解耦
