按类别的工具视图

每个 AgentSpec 通过 mcp_categories 限制可调用的工具；此处数据来自当前 Broker 的 tools/list（与注册时的 category 一致）。

最小接入示例

from pkg.agent import (
    AgentSpec,
    RunContext,
    categories,
    build_linear_mcp_team,
)

# 仅允许 tool_category 为 basic 的工具
a = AgentSpec(
    key="analyst",
    name="分析",
    mcp_categories=categories("basic"),
    system_prompt="你是分析助手，必要时调用工具。",
)

graph = build_linear_mcp_team([a])
result = graph.invoke({
    "context": RunContext(run_id="demo"),
    "data": {"task": "用户问题…"},
    "logs": [],
})

协作：线性团队里上一节点输出写入 data["working_note"]，下一节点自动作为 handoff 使用。自定义分支请使用 build_mcp_workflow_graph + next_map。
